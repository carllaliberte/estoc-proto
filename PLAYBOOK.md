## Combat
1. Salut.
2. Tell visuel (pas un label seul): lame haute = Opening, pointe qui avance = Line, garde basse = Measure.
3. Fenêtre 1200 ms les 2 premiers échanges, 850 ms ensuite.
4. Line bat Opening. Measure lit Line. Opening punit Measure.
5. A / S / D ou 3 boutons. Rate la fenêtre = tu prends l’acier.
6. HP à 0 termine le bout.
